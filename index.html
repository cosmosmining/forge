An open language model, turned into a chip design that is proven correct.

Forge takes an open-source model, makes an integer version of it, generates the hardware for it, and proves that the hardware computes the same numbers as the model. AI agents write the design. A verification gate decides whether it counts.

How it works

Five steps from weights to a verified design

Each step leaves a file that the next step checks. If a check fails, the result does not move forward.

  1. Model inOpen weights are fetched and their checksums compared with the publisher's. So far: Qwen2.5-7B-Instruct and Qwen2.5-0.5B-Instruct, both Apache-2.0.
  2. Integer modelThe model is rewritten in integer arithmetic only, at a chosen weight and activation width. Its accuracy is measured against the original float model on public text.
  3. Hardware generatedAgents write SystemVerilog for each block and for the whole engine. Sizes come from the model's own configuration file.
  4. The gateLint, simulation with coverage, synthesis and timing. The verdict is PASS, FAIL or INCOMPLETE. Only PASS counts, and a test is never relaxed to get one.
  5. ProofThe hardware runs real tokens in simulation. Every intermediate value in every layer is compared with the integer model. One mismatch fails the proof.

How we report

Every number says what kind of number it is

Chip claims are easy to inflate. Forge's tools refuse a number that does not carry its kind and its source, and they refuse a comparison whose numbers do not trace back to its evidence files.

measured
A tool printed it. The file is named.
derived
Arithmetic on measured numbers. The formula is given.
model
Computed from a model of the design, with its assumptions listed.
not yet
Not run. The cell says so and stays empty.

This page quotes no speed-up over a GPU and no cost per token, because neither has been measured on hardware.

Path to silicon

Three levels of proof, in order

Now

Simulation. The design equals the model, passes the gate, and its accuracy against the float model is measured.

Next

FPGA. Tokens per second, time to first token and power from a real board, at batch 1, 8 and 32, with the scripts published.

Then

Test chip. A small design on a shuttle run, compared bit for bit with the same model.

Contact

Bring a model you want in silicon

We are looking for teams who run one open model at volume and want to see what a chip built for that model would do. A pilot ends with a report made of measured numbers.
